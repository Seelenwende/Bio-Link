Verbunden mit der Seite ✅

Wird für Facebook-Beiträge gebraucht – und damit Bild- und Karussellbeiträge auch auf Instagram klappen, solange der Agent nur auf deinem Rechner läuft.

  1. In deiner Meta-App (siehe oben) unter Anwendungsfälle „Seite verwalten“ hinzufügen.
  2. Im Graph API Explorer deine App wählen, die Berechtigungen pages_show_list, pages_read_engagement, pages_manage_posts anhaken und Token generieren.
  3. Token hier einfügen – die Seite findet der Agent selbst.
Erweitert: bestimmte Seite, dauerhaftes Token

Empfohlen: Mit App-ID und App-Geheimnis (App-Einstellungen → Allgemein) wird ein Seiten-Token erzeugt, das nicht abläuft. Ohne gilt das Token nur etwa 1–2 Stunden.

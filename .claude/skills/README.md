# Instagram-Skills für @_seelenwende

Acht Skills, mit denen Claude den Instagram-Account von Seelenwende betreiben
kann — schreiben, planen, gestalten, antworten, auswerten.

## Übersicht

| Skill | Wofür |
|---|---|
| **ig-markenkern** | Fundament: Stimme, Zielgruppe, Angebote, Hashtags, Sicherheit, Kanal-IDs |
| **ig-post** | Feed-Posts, Karussells, Captions, Alt-Texte |
| **ig-reel** | Reel-Skripte mit Hook, Szenen, On-Screen-Text, Cover |
| **ig-story** | Story-Sequenzen, Sticker, Umfragen, DM-Trigger, Highlights |
| **ig-redaktionsplan** | Wochen- und Monatsplanung, Buffer-Entwürfe |
| **ig-community** | Kommentare, DMs, Keyword-Automatisierung, Krisenprotokoll |
| **ig-visuals** | Farben, Schriften, Slide-Layouts, Canva-Briefings |
| **ig-analyse** | Buffer-Metriken auswerten und daraus Schlüsse ziehen |

**ig-markenkern** ist die Grundlage. Alle anderen Skills setzen ihn voraus und
verweisen auf seine Referenzdateien unter `ig-markenkern/references/`.

## Benutzung

Die Skills laden sich selbst, sobald die Aufgabe dazu passt — „Schreib mir ein
Karussell über Hoovering" zieht `ig-post`. Direkt aufrufen geht auch:

```
/ig-post          Karussell über Hoovering
/ig-redaktionsplan  Woche vom 12. Januar
/ig-analyse         Wie lief der September?
```

## Woher der Inhalt stammt

Nichts daran ist erfunden. Die Grundlage sind:

- **`index.html`** in diesem Repository — Farben, Schriften, Claim, Produkte, Preise
- **Veröffentlichte Posts** aus dem Buffer-Konto — Tonfall, Caption-Aufbau,
  Hashtag-Muster, DM-Keywords CARE und PROGRAMM, Posting-Zeiten
- **Die angebundenen Werkzeuge** — Buffer, Canva, Make, MailerLite

## Zwei Dinge, die gesetzt sind

**Sicherheit vor Reichweite.** `ig-markenkern/references/sicherheit.md` gilt für
jeden Inhalt: keine Ferndiagnosen, keine Heilversprechen, keine Rechtsberatung,
Sicherheitshinweis bei Trennungsthemen, und ein Krisenprotokoll mit Notfallnummern
für Deutschland, Österreich und die Schweiz. Diese Datei ist nicht optional.

**Nichts geht ungeprüft raus.** Alles wird in Buffer als `draft` angelegt und vor
dem Erscheinen freigegeben.

## Offene Punkte

- Das **6-Wochen-Programm** wird über das Keyword PROGRAMM beworben, fehlt aber auf
  der Bio-Link-Seite — Preis und Landingpage sind nirgends hinterlegt.
- Wer die **„Seelenwende-Begleiterin"** ist, geht aus den Unterlagen nicht hervor.
- Ein Story-Highlight **„Hilfe"** mit den Notfallnummern sollte dauerhaft
  existieren, falls es das noch nicht tut.
- Es gibt **keine direkte Instagram-Anbindung**: Kommentare und DMs müssen
  hereingegeben werden, Insights-Daten liegen nicht vor.
